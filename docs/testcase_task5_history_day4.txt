## 2. Kiểm thử qua ADB Wireless debugging

### Kết nối và chuẩn bị APK

- Nếu thiết bị đã kết nối, không pair/connect lại hoặc ngắt kết nối. Nếu chưa kết nối, bật **Developer options → Wireless debugging**, pair/connect theo màn hình Android rồi kiểm tra:

```powershell
adb devices -l
flutter devices
```

- Chỉ tiếp tục khi thiết bị kiểm thử hiện trạng thái `device`. Không đưa serial/IP hoặc pairing code vào bảng kết quả.
- Build từ source hiện tại và cài đè để chắc APK có màn Lịch sử Task 5:

```powershell
flutter build apk --debug
Get-FileHash .\build\app\outputs\flutter-apk\app-debug.apk -Algorithm SHA256
adb install -r .\build\app\outputs\flutter-apk\app-debug.apk
```

- `adb install -r` không chủ ý xóa dữ liệu ứng dụng. Nếu cài đè không tương thích chữ ký, dừng và dùng thiết bị kiểm thử khác; không gỡ cài để vượt qua lỗi.
