# Test case — Day 4 Task 4: editor, xác nhận và lưu báo cáo

> Tài liệu này là kế hoạch kiểm thử; các ô chưa chạy để trống. Source Task 4 đã qua widget tests và test suite tổng thể 85/85. Ngày 28/09 APK mới đã được build, cài qua Wireless debugging và mở foreground; chưa chạy thao tác review/save bằng tay. APK/ADB evidence trong tài liệu cũ vẫn là bản trước Task 4.

## Chuẩn bị chung

- Dùng điện thoại Android và mô tả/ảnh tổng hợp, không dùng dữ liệu sự cố, vị trí hay ảnh hiện trường thật.
- Ví dụ mô tả: `Điều hòa khu vực lễ tân không làm mát; nhân viên phát hiện khi kiểm tra.` Ảnh thử, nếu cần, nên là ảnh thiết bị giả lập hoặc ảnh tự tạo không chứa người/biển tên.
- Bấm **Phân tích bằng AI** sẽ gửi nội dung tới Gemini và có thể tính quota. Ghi số request thực tế; không bấm lặp để lấy phản hồi khác nếu lần đầu thành công.
- Khi có thể, dùng bản cài đặt dành riêng cho kiểm thử. Không gỡ ứng dụng, không chạy `pm clear`, không xóa database/ảnh và không cố làm đầy bộ nhớ để tạo lỗi lưu.
- Tab **Lịch sử** chưa đọc repository và màn chi tiết chưa có. Vì vậy, snackbar sau save chứng minh UI nhận kết quả thành công, nhưng chưa chứng minh đọc lại dữ liệu sau khi khởi động lại. Phần kiểm tra persistence đầu-cuối vẫn cần Task 5–7.
- Kết quả mỗi case ghi `PASS`, `FAIL`, `BLOCKED` hoặc `NOT RUN`, kèm ngày/giờ, model Android/API, phiên bản/hash APK và ghi chú ngắn. Không ghi pairing code, debug token, serial ADB hoặc dữ liệu nhạy cảm.

## 2. Test case khi kết nối Wireless debugging với máy tính

### 2.1 Kết nối an toàn bằng ADB

1. Bật **Developer options → Wireless debugging** trên điện thoại, đảm bảo máy tính và điện thoại ở mạng tin cậy.
2. Trên máy tính Windows mở PowerShell. Trong màn hình **Pair device with pairing code**, chạy lệnh rồi nhập mã trực tiếp vào prompt; không lưu hoặc chụp mã:

   ```powershell
   adb pair <IP-điện-thoại>:<cổng-pairing>
   ```

3. Dùng địa chỉ/cổng kết nối hiển thị ở màn Wireless debugging (cổng này khác cổng pairing):

   ```powershell
   adb connect <IP-điện-thoại>:<cổng-wireless-debugging>
   adb devices -l
   ```

4. Chỉ tiếp tục khi đúng thiết bị đang ở trạng thái `device`. Không ghi serial, IP công khai, pairing code hoặc token vào báo cáo kiểm thử.
5. Các lệnh dưới đây giả định đang ở thư mục gốc repo. Chúng không gỡ app hoặc xóa dữ liệu. Nếu cài APK báo lỗi chữ ký/phiên bản, dừng và ghi lỗi; không `uninstall` để vượt qua.

